# Netflix Data Analysis Project

## Project Overview
This project focuses on analyzing the Netflix dataset to understand content distribution, release trends, and other patterns in movies and TV shows.

## Objectives
- Analyze Movies and TV Shows distribution.
- Explore content release trends.
- Identify missing values and handle data cleaning.
- Analyze content duration.
- Explore relationships between numerical features.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Cleaning
- Checked and handled missing values.
- Removed duplicate records.
- Converted data types where required.
- Extracted useful information from existing columns.

## Analysis Performed
- Movies vs TV Shows distribution.
- Year-wise content analysis.
- Country-wise content analysis.
- Duration analysis.
- Correlation analysis.

## Conclusion
This project helped explore the Netflix dataset, perform data cleaning, and identify useful patterns through Exploratory Data Analysis (EDA).
